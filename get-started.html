Setup Guide · ~10 minutes

Connect RSM to Citadel

Install Ronin Server Manager on your dedicated Windows machine and link it to your Citadel portal. Follow these 10 steps and you'll have live, remote server control from any browser.

Steps
1Download RSM 2Install & Launch 3Create Account 4Create Org 5Add Machine 6Generate Token 7Configure RSM 8Connect 9Servers Appear 10You're Live
1
Install · On your dedicated machine

Download Ronin Server Manager

RSM runs directly on the Windows machine that hosts your game servers — not in the cloud, not in Docker. Head to the RSM GitHub releases page, download the latest installer (.exe), and transfer it to your dedicated machine if you aren't already on it.

View Releases on GitHub →
2
Install · On your dedicated machine

Install and Launch RSM

Run the installer. RSM will open automatically after installation. The main window shows your server list — this is where you'll add and manage game server processes locally. RSM also starts a local API on port 3002; this is what the agent uses to control servers.

  • RSM is installed and the main window is open
  • You can see the server list (even if it's empty)
  • The system tray icon is visible — RSM is running in the background
3
Portal · In your browser

Create a Citadel Account

Open the Ronin Citadel portal in any browser. Click Sign Up and choose a username, email address, and password. Once registered you'll land on the dashboard — your control center.

Create Account → Sign In Instead
4
Portal · Organizations

Create an Organization

Organizations are the top-level container for your machines and team members. In the portal sidebar, click Organizations, then + Create Organization. Give it a name that represents your setup — your community name, hosting brand, or just "My Servers" works fine.

💡 You're automatically the Owner of any organization you create. Owners can invite team members, create machines, and manage all settings.
Go to Organizations →
5
Portal · Machines

Add a Machine

A Machine in Citadel represents one RSM installation — the physical or virtual machine where RSM is running. In the portal sidebar click Machines, select your organization from the dropdown, then click + Add Machine. Give it a recognizable name like Home Server or Game Box 1.

Go to Machines →
6
Portal · Agent Tokens

Generate an Agent Token

Click on the machine you just created. In the Agent Tokens section click + Generate. Give the token a label so you can identify it later — for example Home RSM. A long, random token will be displayed. Copy it now.

⚠ This token is RSM's credential to your portal. It is shown only once. If you close the dialog without copying it, generate a new one — the old one is gone.
7
RSM · On your dedicated machine

Configure RSM to Connect

Back on your dedicated machine, open RSM and navigate to its Citadel settings panel. You'll need to enter two things:

Portal URL → e.g. https://citadel.yourdomain.com
Agent Token → the token you copied from Citadel

Paste both values, then click Save.

8
RSM · On your dedicated machine

Connect RSM to Citadel

Click Connect in RSM's Citadel settings. RSM will establish a secure WebSocket connection to the portal backend. Switch back to Citadel in your browser — within a few seconds the machine's status indicator should turn green.

✓ Green dot in Citadel = RSM is connected. If it stays Offline, double-check the portal URL and token, then try connecting again.
9
Portal · Game Servers

Your Servers Appear Automatically

When RSM connects, it sends an announce message listing every game server configured in RSM. Citadel receives this and automatically creates records for each one — no manual entry required. Open your machine in the Machines page to see them.

💡 If you add more game servers in RSM later, they'll appear in Citadel automatically next time RSM connects or announces.
10
All Done

You're Live

Your setup is complete. From any browser, on any device, you can now:

  • View real-time online/offline status for every machine and game server
  • Start, stop, and restart game server processes remotely
  • Monitor live CPU and RAM usage per server
  • Stream the live console output from any server
  • Invite team members and assign them roles
  • Manage Windows Firewall rules (if Ronin Portier is installed)
Open the Portal → Invite Team Members
